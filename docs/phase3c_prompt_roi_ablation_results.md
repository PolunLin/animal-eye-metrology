# Phase 3C Prompt / ROI Ablation Results

本輪依核准方案完成 **2 種點來源 × 2 種框條件 × 3 種 ROI＝12 組對照**。
沿用 COCO 2017 validation 的三張開發圖、六隻動物、12 個人工眼部 Mask 與既有提示，
共保存 144 個眼部分割結果、432 個候選與 108 筆像素距離。
沒有新增資料、重標、訓練、變更模型或重跑 HRNet。

主要發現：原 ROI 下，人工框介入使平均 IoU 由 0.478 升至 0.597，雙眼／跨右眼距離
MAE 由 2.076／3.766 降至 0.428／0.245 px。定位誤差、分割邊界與候選選擇均有影響；
人工點加框仍不能解決 dog 17207 的眼周過度分割。
**只有 A 組屬於本輪全自動提示流程；B、C、D 是人工資訊介入的診斷對照。**
本輪完成 Phase 3C 的這項對照實驗，不代表整體系統或泛化驗收已完成。

## Frozen Scope and Protocol

| 項目 | 固定設定 |
| --- | --- |
| 資料與選擇方式 | COCO 2017 val；沿用既有已選、已人工標註的 20247（熊）、125405（狗）、333069（長頸鹿）；不是新增隨機抽樣 |
| 身分與側別 | 沿用既有六個動物預測與固定配對；解剖左右，不依畫面左右重排，不以 GT 交換側別 |
| 定位 | 凍結 HRNet-W32 / AP-10K 原始眼點、分數與雙眼距離；不重新推論 |
| 人工介入 | 既有原圖上保存的 12 組人工點／框；不是由評估 Mask 重心或 Mask 外接框自動產生 |
| 分割模型 | SAM 2.1 Tiny；既有 checkpoint 與官方來源版本 |
| 執行 | 原 `.venv`；CPU、FP32、batch=1、4 threads、seed=42；沒有安裝或升級套件 |
| A | HRNet 點，無框；全自動比較組 |
| B | 人工點，無框；診斷定位點替換 |
| C | HRNet 點＋人工框；診斷額外區域資訊 |
| D | 人工點＋人工框；診斷兩種資訊聯合作用 |
| ROI | 各組均為 0.5×／1×／1.5×；中心永遠為原 HRNet 眼點 |
| 候選選擇 | `multimask_output=True`；3 個候選，取模型分數最高者，平手取第一個；logits > 0；無後處理 |
| 呼叫隔離 | 每次 `mask_input=None`；同眼同 ROI 可共用影像 embedding，不傳入前次 Mask |
| 重用／新增 | A_r100 的 12 個原結果直接重用；132 次新增提示推論、36 次影像編碼 |
| 評估 | 推論產物先凍結，再載入既有主要人工 Mask 基準；不以評估最佳候選替代主結果 |

令 d 為凍結 HRNet 左右眼距離，`L0=max(32,2*d)`、`L=α*L0`。
裁切左上角向下取整、右下角向上取整，超出影像處裁至原圖邊界。
倍率作用於包含最小值在內的整個 L0。原圖浮點提示先依原流程轉 float32，再減 ROI 原點；
提示不額外加 0.5。原圖座標、ROI、點框衝突均完整保存。
因此 B、D 只替換提示點，沒有同時把裁切中心移至人工點。

原 ROI 下，點替換 B−A 與框加入 C−A 都有改善，但作用不相加：
IoU 交互差 `(D−C)−(B−A)` 在 0.5×／1×／1.5× 分別為 −0.0265／−0.0561／−0.0699。
這描述加框後人工點替換的額外收益較小，不表示 HRNet 普遍比人工定位更好。
A_r050 雖改善平均距離，12 眼中仍有 6 眼 IoU 退步；不能稱全面改善或直接升為部署預設。

再次說明不能從平均分割重疊推定量測精度。

## Interpretation and Next Steps

| 優先順序 | 建議 | 理由與下一步驗證 |
| --- | --- | --- |
| 1 | 研究由模型產生的局部眼框／眼部範圍限制 | 本輪原 ROI 下，框介入的平均 IoU 與量測改善明顯；下一版須完全從自動預測產生框，與 A 基線配對比較，不使用人工框取得部署分數 |
| 2 | 對 dog 17207 研究眼裂邊界精修 | 人工點框及最佳候選仍有限；評估局部分割或專用眼部分割方案，保持既有目標定義；模型／訓練選擇另提案 |
| 3 | 研究候選品質檢查與拒絕輸出 | 大片頭部、碰 ROI 邊界、候選差異可成為研究訊號；閾值與規則須用獨立資料驗證，不能依 GT 選候選，模型分數也不是可見性機率 |
| 配套 | 保留 A_r050 作全自動量測比較候選，建立獨立驗證圖 | 三圖距離改善但有局部退步；依 image_id 切分開發／留出，先定資料及驗收方案，不能直接宣告最佳預設 |

本輪沒有替換正式方法或擴大資料。下一輪的新資料、架構、量測資格或評估定義，
應先整理選項與驗收條件給專案負責人決定。

## Limitations

| 限制 | 對解讀的影響 |
| --- | --- |
| 只有三張已反覆查看的開發圖 | 144 個條件結果不是 144 個獨立樣本；不報泛化保證、顯著性或由此推算全資料集成績 |
| 參考仍是人工 Mask | 既有四眼重標已顯示參考變異；本次沿用主要版本，沒有把某次人工標註當成物理真值 |
| ROI 同時改變上下文與有效尺度 | 此實驗能描述條件差異，不能獨立辨認「只因尺度」或「只因上下文」的因果效應 |
| 眼睛很小 | 少量像素可大幅改變 IoU；須聯合查看 Mask 面積、重心與距離 |
| B／C／D 含人工資訊 | 只能診斷瓶頸，不能宣稱已自動得到同等表現；D 的裁切中心仍由 HRNet 決定 |
| 固定六個動物與配對 | 不評估未檢出的動物、新的身分配對錯誤或任意輸入端到端成功率 |
| 可見性／側別可靠性未驗收 | 非空 Mask、落點命中與低距離誤差都不是可接受量測的充分條件 |

## Reproduction

設定為 `configs/prompt_roi_ablation.toml`；路徑相對設定檔解析。
既有產物拒絕覆寫。重跑時複製設定、指定全新輸出目錄，再為各階段加入 `--config`。
下列為本輪實際使用的命令入口；不會下載資料或權重。

```sh
.venv/bin/python -m animal_eye_metrology.prompt_roi_ablation --stage prepare
.venv/bin/python -m animal_eye_metrology.prompt_roi_ablation --stage run
.venv/bin/python -m animal_eye_metrology.prompt_roi_ablation --stage evaluate
.venv/bin/python -m animal_eye_metrology.ablation_visualization --output outputs/phase3/prompt_roi_ablation_v1
.venv/bin/python outputs/phase3/prompt_roi_ablation_v1/audit/independent_check.py
.venv/bin/ruff check src tests app outputs/phase3/prompt_roi_ablation_v1/audit/independent_check.py
.venv/bin/ruff format --check src tests app
.venv/bin/python -m pytest -q
.venv/bin/python -m animal_eye_metrology.prompt_roi_ablation --stage finalize
.venv/bin/python -m animal_eye_metrology.prompt_roi_ablation --stage verify
```

本輪推論執行段內部計時為 15.681 s，包含模型載入、重用結果讀取與產物寫檔；
其中模型載入 1.160 s，36 次影像編碼合計 12.461 s。
計時不含先前 HRNet、重用的 12 次歷史推論、評估、圖表、測試及本次匯入／來源驗證；
不是任意圖片端到端延遲或效能基準。詳細版本與分段時間見 `runtime.json`、`audit/inference.log`。

成功推論完成後，測試審查發現並修正影像載入失敗時的快取狀態更新順序，
避免失敗後錯用前圖。實際 144 個結果皆成功，該失敗路徑未觸發，因此不重跑或替換結果。
實際推論程式另凍結於 `audit/inference_runner.py`，修正說明與 SHA 見 `audit/inference_code_record.json`；
最終可重現程式保存在 `provenance/`，並有故障回歸測試。
