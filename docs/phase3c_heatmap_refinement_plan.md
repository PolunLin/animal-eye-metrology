# Phase 3C Heatmap Guided Eye Refinement Plan

Status: Planning proposal. 2026-11-08.

依專案負責人重申的方向，保留 A_r100 基線，不將 γ＝0.5 幾何框晉級，
也不事後以 γ＝0.3 改寫前輪主方法。下一輪先判斷凍結熱圖是否具有可用的範圍資訊，
再分開驗證區域提示與原圖外觀邊界精修。狗 17207 是必要難例，但所有 12 眼都要評估。
本次完成來源與幾何中繼資料檢查及規劃，未實作新方法或產生新分割成績。

狗17207的參考Mask只有15／14個原圖像素，邊界仍須回到原圖外觀研究。

## H0 Diagnostic Scope

H0沿用COCO 2017 val的20247、125405、333069、固定六個動物與解剖左右，
讀取原 `auto_eye_localization_poc_v1/pose/` 的凍結熱圖、幾何與眼點。
不重新執行HRNet或SAM、不改點、不產生新眼部預測Mask，也不修改既有基線。

建議以下規則於執行前核准並凍結：

| 項目 | H0規則 |
| --- | --- |
| 使用通道 | 原AP-10K的L_Eye、R_Eye；不依GT交換通道 |
| 固定響應層級 | `τ = 0.25, 0.50, 0.75`；在原生熱圖取 `H >= τ * max(H)`，最大值須有限且>0；三層級全報，不逐眼挑最佳 |
| 響應區域 | 取包含全域最大值的8連通區；最大值平手依原生row-major順序選第一個；其他區域不併入 |
| 區域框 | 原生連通區的外接框，以格中心加減半格定義外緣，再依原有codec座標與幾何轉換映射回原圖 |
| 空間範圍 | 保存原始映射框，再裁至凍結A_r100 ROI與影像邊界；紀錄裁切，不移動ROI或用GT擴框 |
| 顯示 | 原生格點、原圖熱圖疊圖與局部原圖並列；顯示插值方式，插值不當作新增解析度 |
| 異常 | 非有限值、非正峰值、無效區域／轉換記為診斷失敗；不以人工框回退 |
| 計畫規模 | 12眼×3層級＝36個診斷區域；不是36個新SAM分割結果 |

這三個層級是診斷探針，沒有「25%／50%／75%位置機率」的意義。
外接框只表示響應的空間範圍，不命名為已驗證的眼睛框。
這個原生格外緣約定必須有合成座標／仿射回轉測試，避免半格偏移被誤認為定位改善。

推導區域的步驟只讀模型輸出與幾何；保存並封存36個區域後，才載入既有人工參考作下表評估。
不由人工Mask的大小／位置選τ、修正中心或選連通區。

| 診斷 | 比較方式 |
| --- | --- |
| 範圍涵蓋 | 每眼GT像素被框涵蓋比例、完整涵蓋眼數、完全漏蓋眼數；沿用半開框與原圖像素中心規範 |
| 緊密程度 | 每眼框面積／參考Mask面積、寬高、裁切比例；與已保存γ0.3、γ0.5幾何框並列 |
| 定位不變量 | 原HRNet點與側別保持一致；不把響應框中心當新定位成績 |
| 難例與反例 | dog13692左右眼、dog17207雙眼、giraffe599888右眼、熊原本良好而退步的案例；另報完整12眼 |
| 相較幾何框的價值 | 各固定τ是否在平均涵蓋不下降時減少平均面積比，且無新增完全漏蓋；逐眼取捨完整揭露 |

若某固定τ展現範圍／面積的改善，可據此提出H1候選；這只代表值得測試SAM提示，
不表示分割或距離已改善。若各層級只是得到更大的Gaussian響應框，應建議優先研究H2，
不為了使用熱圖而把它當成眼睛尺寸。以三圖選出的τ仍屬開發選擇，需明確記錄並另做留出驗證。

## Appearance Refinement Options

| 方法 | 研究價值 | 風險與前置條件 |
| --- | --- | --- |
| **Mask初始化的局部GrabCut** | 可沿用原圖、既有SAM Mask／logits，以色彩模型和像素間邊緣關係形成新邊界；不需訓練新神經模型 | 不理解眼裂語義；黑毛、反光及錯誤初始化可失敗；種子來源、確定／可能標籤與迭代數需另外凍結 |
| 局部梯度／輪廓精修 | 可檢驗邊緣是否有助收縮眼周過度分割 | 細小眼睛、毛髮邊緣和弱對比會混淆；不能把最大梯度當成眼裂真值 |
| 專用分割或微調 | 有機會學到既有人工眼部Mask的語義定義 | 需要更多獨立影像與標註、資料切分和訓練驗證；不能從這12眼宣稱成功 |

GrabCut可以用Mask初始化並處理前景／背景的確定與可能標籤；矩形初始化則把框外視為確定背景。
因此本案若採用它，優先研究Mask初始化，避免把漏蓋框直接寫成不可修正的背景。
HRNet點、SAM高logit或熱圖高響應都不能自動當成正確的確定前景。
以上能力依據 [OpenCV GrabCut官方文件](https://docs.opencv.org/4.13.0/d8/d83/tutorial_py_grabcut.html)；
它在動物眼部是否有效仍需實測，未於本輪選定為正式方法。

## Future Controlled Comparison

若H1與H2的規則獲核准，建議保留四個分支，區分區域提示與外觀精修的影響：

| 分支 | 用途 |
| --- | --- |
| A_r100原輸出 | 既有主對照 |
| H1原輸出 | 區域提示的單獨效果 |
| A_r100＋同一H2精修 | 外觀精修本身的效果 |
| H1＋同一H2精修 | 聯合作用；精修設定不得因分支而調整 |

A_r050與γ0.3點＋框另作實用比較。H1固定原眼點／ROI與SAM候選選擇，
H2保存精修前後結果；不一次加入新的點位、ROI倍率、候選重排與每眼參數。
原始與精修結果都報IoU／Dice、面積、重心、雙眼及跨右眼距離，失敗與缺值保留。
H2會改變Mask，因此必須重新量測全部距離，不能沿用原重心。

狗17207須檢查是否減少眼周過度分割且保持目前的可見眼部Mask定義；
不能改成僅抓深色瞳孔而宣稱邊界改善。對所有眼睛與原本良好案例同樣檢查退步。
正式分割／量測晉級條件待H1／H2提案時先凍結；H0本身沒有模型晉級判定。
