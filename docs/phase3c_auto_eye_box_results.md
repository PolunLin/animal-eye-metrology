# Phase 3C Geometric Automatic Eye Box Results

依已核准的 [Automatic Eye Box Proposal](phase3c_auto_eye_box_proposal.md)，
完成固定 1× ROI 的六組幾何自動框實驗，新增 **72 個眼部結果、216 個候選、54 筆距離記錄**。
全部推論成功且 Mask 非空。**事先指定的主方法 γ＝0.5、點＋框未通過晉級條件**：
相對 A_r100 雖降低兩類距離 MAE，但平均 IoU 下降、重心偏差增加。
γ＝0.3 點＋框保留為探索候選，與 A_r050 有取捨，未替換正式預設或事後改寫主方法。

## Frozen Protocol and Execution

| 項目 | 實際執行 |
| --- | --- |
| 資料版本與選擇 | COCO 2017 validation；沿用既有開發圖 20247（熊）、125405（狗）、333069（長頸鹿）；六隻動物、12 眼，無新增抽樣 |
| 既有參考 | 主要人工 Eye Mask 版本、固定實例配對與解剖左右；未重標、交換左右或修改身分 |
| 自動框 | 以凍結 HRNet 眼點為中心，方框邊長 `max(8,γ*d)`；d 為原流程 float64 預測眼距；γ＝0.3／0.5／0.7 |
| 框座標 | 保存原始浮點框、邊界裁切後的原圖 float32 框，再減 ROI 原點；72 個框均有效且無邊界裁切 |
| ROI | 逐眼直接沿用 A_r100 的凍結整數座標，經評估檢查完全一致；未重新計算裁切、未改中心 |
| 提示 | 每種框大小各做「HRNet 點＋框」及「只有框」；只有框的 points、labels 均為 None；幾何中心仍由 HRNet 決定 |
| 主方法 | `auto_box_k050_point`，在實驗前指定；其餘五組為診斷／敏感度 |
| 模型與環境 | 原 SAM 2.1 Tiny、CPU FP32、batch=1、4 threads、seed=42；原 `.venv`，沒有安裝或升級套件；HRNet 未重跑 |
| 候選規則 | 每次三候選，最高模型分數者（平手第一個），logits > 0；`mask_input=None`；無後處理或框硬截斷 |
| 實際計算 | 12 次影像編碼、72 次提示解碼；六組同眼共用相同 ROI 編碼，不傳遞前次 Mask |
| 輸入隔離 | 新請求僅含原圖、自動預測與幾何；不含人工點、人工框、annotation_id 或 Eye GT；預測封存後才載入人工參考與配對 |
| 基線 | A_r100、A_r050 已保存結果；另保存 A_r150、C_r100 作背景參考；C 仍是人工框診斷，不是自動上限 |

三種 γ 與 8 px 下限是核准的工程假設，不是擬合人工框所得的眼睛尺寸。
本輪全部新組都是自動提示，與前輪 B／C／D 人工介入不同；
但仍只評估六個已配對動物，不代表任意影像的端到端成功率。

每組分割固定 12 眼、雙眼距離 6 筆、跨右眼距離 3 筆，全部可定義。
IoU／Dice 越高越好；重心與距離誤差單位為原圖 px，越低越好。
重心為前景像素中心 `(x+0.5,y+0.5)` 的平均，距離為重心歐氏距離；參考為主要人工 Mask。
失敗／空 Mask 在平均 IoU、Dice 計 0 並另報，距離缺值不補零；本輪未出現缺值。
所有 HRNet 點保持相同，命中參考 Mask 仍為 **9/12**，平均距人工 Mask 重心偏差為 **2.248 px**。
這是定位不變量，不是新定位精度進步，也不是相對真實瞳孔的誤差。

## Promotion Decision

以下依實驗前核准的完整精度判準判定；工程驗證與研究成效分開。

| 判準 | 主方法 γ＝0.5 點＋框 | 結果 |
| --- | --- | --- |
| 無推論失敗／空 Mask | 0／0 | 通過 |
| 重心與兩類距離完整 | 12/12、6/6、3/3 | 通過 |
| 無原本 IoU>0 的眼新增 IoU=0 | 0 眼 | 通過 |
| 平均 IoU 高於 A_r100 | 0.243 < 0.478 | **不通過** |
| 平均重心偏差不增加 | 2.137 > 1.576 px | **不通過** |
| 雙眼距離 MAE 降低 | 1.717 < 2.076 px | 通過 |
| 跨右眼距離 MAE 降低 | 1.432 < 3.766 px | 通過 |
| 全部研究門檻 | 細分 10 項通過 8 項 | **未晉級** |
| 工程與產物驗證 | 159項測試、422個檔案雜湊、72個Mask重建與54筆距離重算通過 | 通過 |

主方法相對 A_r100 有 3 眼 IoU 改善、9 眼退步。
距離是兩個重心共同決定，位移可以部分抵消；距離 MAE 改善不能補償輪廓與重心退步。
相對 A_r050，主方法的 IoU、重心及兩類距離指標均較差。

Δ 為目標減基準；IoU 正值與誤差負值代表改善。
γ＝0.3 點＋框相對 A_r100 有 7 眼改善、5 眼退步；對 A_r050 則是 6 眼改善、6 眼退步。
相對小 ROI 的 IoU 僅增加 0.0042、雙眼 MAE 降低 0.1574 px，
但平均重心偏差增加 0.0703 px、跨右眼 MAE 增加 0.1219 px。
因此它是探索候選，不能改稱本輪預先指定主方法成功，也不能稱全面優於 A_r050。

移除正點後，三種 γ 的平均 IoU 皆下降；重心與距離的變化不一致。
本輪結果不支持全面改用只有框；只有框仍依賴 HRNet 生成中心，並未實現新的定位器。
完整 19 組配對、228 筆逐眼差異與 171 筆距離差異見對應 CSV。

## Box Coverage and Failure Diagnosis

| γ | 完整涵蓋參考眼數 | 平均參考像素涵蓋率 | 平均框面積／參考面積 | 點＋框的預測框外比例均值 |
| --- | --- | --- | --- | --- |
| 0.3 | 6/12 | 87.99% | 3.602× | 6.88% |
| 0.5 | 12/12 | 100.00% | 9.393× | 3.30% |
| 0.7 | 12/12 | 100.00% | 18.411× | 13.31% |

框涵蓋率與框外比例以原圖像素中心落於半開框 `[x0,x1)×[y0,y1)` 計算；只供事後評估。
同 γ 的兩種提示使用完全相同框，因此涵蓋率相同。
面積比是每眼「方框幾何面積／人工 Mask 面積」的平均，不是相對人工提示框的比例。
γ＝0.5／0.7 雖完整包含所有參考眼部，仍常分到眼周；框涵蓋完整並不足以提供精細邊界。
γ＝0.3 較局部，但熊四眼及兩個長頸鹿眼部未完全落在框內，顯示固定比例也有漏蓋風險。

| 案例 | 實測／視覺觀察 | 解讀 |
| --- | --- | --- |
| dog 13692 右眼 | A_r100 IoU=0；γ0.3 點框=0.138，重心偏差4.492 px，Mask109像素、參考15；其框完整涵蓋參考 | 從零重疊改善，仍未得到可靠眼部輪廓或重心；幾何框未修正定位中心 |
| dog 13692 左眼反例 | A_r100 IoU=0.692；γ0.3=0.241、γ0.5=0.0448 | 不能只報同隻動物右眼改善而忽略左眼退步 |
| dog 17207 左／右眼 | γ0.3 點框 IoU=0.288／0.259，Mask面積52／54、參考15／14 | 較局部但仍過度包含眼周，邊界問題持續 |
| giraffe 599888 右眼 | γ0.3 框只涵蓋50%參考，IoU=0.269，低於A_r050的0.379；γ0.5完整涵蓋但IoU=0.173 | 中心與尺度均有取捨，單一比例不能兼顧局部性與涵蓋 |
| bear 588042 左眼 | A_r100 IoU=0.900、重心偏差0.088 px；γ0.5點框=0.316／1.836 px，圖上有更多上方眼周 | 加框也會破壞原本良好的案例 |
| bear 587181 右眼 | γ0.3框涵蓋65%參考，選中Mask仍有15%像素在框外 | Box prompt是軟提示；本輪沒有硬截斷Mask |

三候選排序確實造成部分差距，但主方法即使事後每眼挑 GT IoU 最佳候選，
平均 IoU 也只有 **0.401**，仍低於 A_r100 的 0.478。
在固定此組生成結果的前提下，單純重排現有候選不足以恢復基線。
狗 17207 左／右眼跨本輪六組全部18候選，各眼最高 IoU 也只有約 **0.3125／0.2745**，
支持後續研究眼部外觀與邊界；這些候選最佳值只用作診斷，沒有替換主輸出。

## Limits of the Result

這是三張反覆查看的開發圖，72個條件結果不是72個獨立樣本，不作顯著性或泛化結論。
參考為既有人工眼部Mask，並非物理真值；細小眼部受少量像素與重標變異影響。
本輪固定動物配對與側別，未測新的偵測漏失或任意輸入流程。
可見性與量測資格仍為unverified；非空Mask、框涵蓋完整或距離誤差下降都不能單獨證明量測可靠。
